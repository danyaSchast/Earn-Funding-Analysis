Цей бот розроблений для визначення можливості заробітку на стейкінгу(депозит під відсотки) криптовалюти на біржі "ByBit". 
Бот рахує кінцевий прибуток, ураховуючи APR(Annual Percentage Rate - Річна Відсоткова Ставка), час, на який відкритий стейкінг(прибуток нараховується щогодинно),
комісію за відкриття та утримання позиції.Щодо результатів - так, зазвичай прибуток буде від'ємний, проте бот я створював заради відслідковування прибуткових
ситуацій, в яких APR може сягати 500%.Пропоную переглянути можливі стейкінги з привабливими відсотками командою "/availableEarn"
